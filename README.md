## Features

- Change extension for all files in a folder at once
- Filter by current extension before applying changes
- Preview complete list of changes before committing
- Works recursively through subfolders
- Undo log saved automatically after each operation

## FAQ

**Will changing the extension corrupt the file?**  
Only if the new extension doesn't match the actual format. The tool warns you about common mismatches.

**Can I set a completely custom extension?**  
Yes, type any extension you need - not limited to a preset list.
